# Mailstack

This project's memory is files in the repo, so it survives a crash and a gap of months.

1. Read `NOW.md` at the start of a task. It is the current status.
2. Standing rules load from `.cursor/rules/`.
3. Root `CONTEXT.md` is the archive of past decisions. Open it only when the user asks about an old decision.
4. Work in the one platform folder the user named. The folder map is in `.cursor/rules/platforms.mdc`.
